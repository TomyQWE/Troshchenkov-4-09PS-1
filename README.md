# RZDProject — Обслуживание объектов инфраструктуры РЖД

Мобильное приложение для Android, предназначенное для обслуживания объектов инфраструктуры РЖД.

---

## 📱 О приложении

Приложение позволяет:
- Система авторизации
- Просмотр графика обслуживание,так же удаление и изменение
- Просмотр заявок на обслуживание. Принять или отклонить
- Просмотр объектов обслуживания
- Просмотр сотрудников и их контактных данных(телефон,почта)
- Просмотр бригады и их состава
- Система поиска на всех страницах кроме бригады
